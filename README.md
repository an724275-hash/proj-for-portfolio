# TENSION

Интерактивный веб-эксперимент Артёма Назарова: акустический объект, который раскрывается при прокрутке и реагирует на синтезированный звук. Это художественная модель для портфолио, не инженерная симуляция и не страница продажи существующего устройства.

Проект заменяет прежний фестивальный лендинг «СЕВЕР». Его предыдущий вариант сохранён в истории Git. Эта переработка пока не опубликована; адрес прежнего сайта не подтверждает наличие TENSION в продакшене.

## Запуск

Нужны Node.js 22.12+ и npm. Установка зависимостей требует доступа к npm; работа собранного приложения не требует внешнего API.

```sh
npm ci
npm run dev
```

Открой локальный адрес, указанный Vite в терминале. Для проверки и сборки:

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Команда `preview` позволяет проверить именно собранный сайт, но не является сервером для продакшена. Команды сборки и тестирования ничего не публикуют.

## Управление

- Один короткий вертикальный жест переключает целую сцену. Шесть сцен: объект, устройство, обратная сторона, поверхность, импульс и инструмент. Поддерживаются колесо, свайп, стрелки, Page Up/Down, Home/End и ссылки 00–05; работает история браузера.
- Инерция тачпада не перескакивает через несколько сцен. На коротком экране сначала прокручивается содержимое текущей панели, чтобы все настройки оставались доступны.
- На обратной стороне ползунок вращает объект на 360°. В сцене поверхности можно менять материал и направление света. «Дать импульс» запускает затухающую визуальную вибрацию без звука.
- Курсор слегка меняет ракурс. На телефоне управление не требует наведения мыши.
- «Движение: выкл» отключает плавное движение и анимацию сигнала. Системная настройка `prefers-reduced-motion` учитывается при запуске и при изменении.
- «Включить звук» запускает локальный Web Audio-синтезатор. Переключение тембра само по себе звук не включает.
- Частота основного тона: 55–220 Гц, начальное значение 110 Гц. Тембры содержат дополнительные гармоники и модуляцию.
- Громкость интерфейса: 0–50%, начальное значение 18%. Это уровень цифрового сигнала, не измерение звукового давления. Начинай с тихой громкости устройства.
- «Импульс»: синусоидальные тоны и тихий прямоугольный субтон. «Дрейф»: расстроенные треугольные тоны. «Зерно»: основной тон с фильтрованным шумом.
- «Алюминий» и «Графит» меняют материал объекта, не звук.

Осциллограмма берётся из реального выходного аудиосигнала. Реакция мембраны основана на его амплитуде, но её движение художественно усилено и не описывает физику конкретного динамика.

## Технологии и данные

Three.js рисует процедурную 3D-сцену; Web Audio API создаёт звук без внешних семплов. Vite собирает JavaScript, CSS и шрифты Anton/Manrope из локально установленных пакетов Fontsource. При открытии сайта шрифты загружаются с того же хостинга, а не с Google Fonts.

Приложение не запрашивает микрофон, не записывает аудио, не отправляет настройки на сервер и не содержит аналитических трекеров. Кнопка портфолио ведёт на внешний сайт автора. Хостинг может вести собственные серверные журналы, которые не управляются этим приложением.

## Ограничения и проверка

- Звук требует Web Audio и явного действия пользователя. При уходе со сцены инструмента, скрытии вкладки или прерывании аудио браузером воспроизведение останавливается; возвращение на страницу не включает его автоматически.
- При недоступном или потерянном WebGL-контексте остаются статичный SVG-постер, текст и звуковое управление. Без JavaScript доступны описание и постер, но не интерактивный инструмент.
- Качество и скорость 3D зависят от браузера, GPU и разрешения экрана. Статичный постер не воспроизводит все состояния объёмной сцены.
- Unit-тесты проверяют математику переходов и жизненный цикл аудио, включая быстрые включения/выключения, смену тембра и прерывание браузером. Web Audio в тестах заменён mock-контекстом: это не проверка звучания или производительности на реальном устройстве.
- В репозитории нет backend, аккаунтов, платежей или физических товаров. Настройки не сохраняются между перезагрузками.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Текст, навигация и доступные элементы управления |
| `src/style.css` | Адаптивная композиция и состояния интерфейса |
| `src/main.js` | Связь прокрутки, элементов управления, сцены и звука |
| `src/scene.js` | Камера, освещение и рендеринг |
| `src/object.js` | Процедурная геометрия и материалы объекта |
| `src/motion.js` | Расчёт переходов между сценами |
| `src/pager.js` | Полноэкранная навигация, жесты, фокус и история |
| `src/audio.js` | Синтезатор и управление ресурсами Web Audio |
| `src/*.test.js` | Тесты без запуска браузера |

Зависимости сохраняют собственные лицензии; условия шрифтов находятся в соответствующих пакетах Fontsource.
